# FQNovel Desktop

FQNovel Desktop 是一个本地桌面客户端。项目使用 Electron、React 和 Node.js 实现客户端界面与业务功能，并由独立的 Java Worker 承载 unidbg 模拟环境。

## 项目来源与致谢

本项目基于 [zero199901/fqnovel-unidbg](https://github.com/zero199901/fqnovel-unidbg) 进行桌面客户端方向的重构和功能扩展。原项目为本项目的 unidbg 模拟、接口签名及章节内容处理提供了重要基础。

感谢原项目作者及相关开源项目贡献者的研究、实现与分享。本项目是独立的二次开发项目，并非原项目作者维护或发布的官方版本。
