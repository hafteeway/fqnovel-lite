# FQNovel Lite

简洁的番茄小说桌面书籍搜索与导出工具。可导出TXT与EPUB文件。

> 仅限在符合当地法律、平台规则和版权要求的前提下，用于个人学习与研究。

## 功能

- 按书名或作者搜索，展示封面、评分、字数、章节、状态与标签。
- 默认导出为 TXT 或 EPUB；EPUB 包含可点击目录和正文标题。
- 下载支持进度、暂停、继续、失败重试、取消与恢复。
- 已完成任务可整理历史记录，导出文件不会被删除。
- 搜索记录、默认导出目录和格式会保存在本机。

## 下载

在 [Releases](../../releases) 页面选择适合你的版本：

| 版本 | 适用设备 | 文件 |
| --- | --- | --- |
| Electron for macOS | Apple 芯片 Mac | `.dmg` |
| Electron for Windows | Windows x64 | 安装版或便携 `.exe` |
| SwiftUI for macOS | Apple 芯片 Mac，macOS 14+ | `.dmg` |

macOS：打开 DMG 后将 App 拖入 Applications + 应用程序。Windows：运行安装程序，或直接打开便携版 EXE。

## 使用

1. 打开应用，输入书名或作者并搜索。
2. 在“导出设置”选择 TXT/EPUB 与保存位置。
3. 在结果中点击下载，在“下载任务”查看进度。
4. 完成后使用“在 Finder 中显示”或 Windows 文件资源管理器打开文件。

## 从源码运行

开发环境需要 Node.js 22.12+、Maven 与 Java。安装依赖后：

```bash
npm ci
npm start
```

常用检查：

```bash
npm test
npm run typecheck
npm run build:renderer
npm run build:worker
```
